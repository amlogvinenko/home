## 1. Цель работы

Развернуть два контейнера:
- `Velocity` (proxy) на порту `25565` с доступом с хоста;
- `Paper 1.16.5` (backend) на порту `25570` только внутри docker-сети.

Дополнительно:
- сохранить данные мира backend через том/маунт;
- настроить `MOTD` с ником;
- подтвердить, что backend напрямую с хоста недоступен.

## 3. Реализация

Проект развернут через `docker compose` с сервисами:
- `velocity` (прокси);
- `paper` (backend).

Ключевые условия:
- наружу опубликован только `25565`;
- backend работает только внутри docker-сети;
- данные backend сохранены на хосте через маунт;
- в `server.properties` выставлены требуемые параметры (`motd`, `online-mode`, `server-port`, `query.port`).

## 4. Проверка

Базовые команды проверки:
- `docker compose up -d --build`
- `docker compose ps`
- `python mc_motd_retriever.py localhost 25565`
- `python mc_motd_retriever.py localhost 25570` (ожидается недоступность)

Ожидаемый результат:
- `25565` отвечает и отдает корректный `MOTD`;
- `25570` не доступен напрямую с хоста.
